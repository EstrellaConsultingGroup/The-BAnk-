## Prompt template for the image model

```

saturated sunset neon palette, high contrast, cinematic lighting, shallow depth of field,
large empty area at the bottom third for big text, no text, no logos, no watermarks.
```

Text is never generated by the model — the pipeline draws it (1–3 words, white + one yellow accent word).
